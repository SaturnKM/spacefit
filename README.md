# Spacefit – Outfits from Orbit 🪐

Spacefit is a mobile shopping app for space-themed clothing, built with Flutter.
Users can create an account, search and filter the collection by category, view product
details, pick a size and quantity, save favourites, manage their cart and place an order
with pay-on-delivery. All data is saved on the device.

The app has a custom icon and splash screen, a dark/light theme with a circular reveal
animation, and animations throughout: staggered fade-ins, bouncy feedback, floating planets,
hero transitions and haptic feedback.

## Features

- **Sign in / Create account** (saved on the device)
- **Home**: search, categories (Tops, Dresses, Shoes, Bags) and a product grid
- **Product page**: choose size and quantity, add to cart, love ❤️ an item
- **Loved** list and **Cart** (change quantities, swipe left to delete)
- **Checkout**: delivery form, option to save details, pay on delivery (demo)
- **Dark / light theme** with a circular reveal animation from the theme button
- **Animations** throughout: fade-ins, bouncy "pop" effects, floating planets, page transitions, product "hero" animation, and phone vibration feedback
- Custom **app icon** and **splash screen**
- Cart, loved items, account and theme are **saved** between app launches

## Requirements

- [Flutter](https://docs.flutter.dev/get-started/install) **3.10 or newer** (Dart 3)
- An Android emulator, iOS simulator, or a real phone with USB debugging on

Check your setup with:

```
flutter doctor
```

## How to run

1. **Clone the repository**
   ```
   git clone https://github.com/SaturnKM/spacefit.git
   cd spacefit
   ```

2. **Install the packages**
   ```
   flutter pub get
   ```

3. **Run the app** (with a phone or emulator connected)
   ```
   flutter run
   ```

### (Optional) Regenerate the icon and splash screen

They are already generated in the project. Only run these if you change the images in `assets/`:

```
dart run flutter_launcher_icons
dart run flutter_native_splash:create
```

## Project structure

```
lib/
  main.dart                     → all the app code (see sections below)
assets/
  app_icon.png                  → app icon
  app_icon_foreground.png       → Android adaptive icon
  splash.png                    → splash screen image
  splash_android12.png          → splash screen image for Android 12+
android/, ios/                  → platform projects (generated by Flutter)
pubspec.yaml                    → packages, icon and splash settings
```

`lib/main.dart` is split into clearly marked sections:

| Section | What it contains |
|---|---|
| Palette | Colors for dark and light themes, text styles |
| Data / store | Products list, accounts, cart, loved items, saving/loading |
| Notifications | Top toast messages and the "Added to cart" sheet |
| App + theme switch | App setup and the circular theme animation |
| Shared widgets | Planet drawing, buttons, text fields, empty states, page transition |
| Juice widgets | Reusable animations: `Pressable`, `FadeIn`, `Pop`, `Floating`, `Pulse`, `stagger()` |
| Screens | Auth → Home → Product → Loved → Cart → Checkout → Confirmation |
